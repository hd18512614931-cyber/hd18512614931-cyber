## 我的工作方式 / How I Work

1. **先定义可验证目标**：明确用户操作、输入输出和验收标准，而不是只描述视觉效果。
2. **快速建立可运行原型**：先打通核心流程，再逐步优化结构、性能和体验。
3. **保留工程证据**：通过提交记录、测试结果、演示视频和文档说明项目如何完成。
4. **区分源码、素材与产物**：避免把缓存、密钥、本机路径和无关构建文件带入仓库。
5. **诚实标注项目边界**：明确原创、二次开发、研究参考、Fork 和暂未公开的内容。
